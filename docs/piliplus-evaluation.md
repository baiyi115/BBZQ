# PiliPlus 功能借鉴评估

研究基线：[PiliPlus `cab0114a`](https://github.com/bggRGjQaUbCoE/PiliPlus/tree/cab0114a21ce7fad5b90b9a4d788d35d313d25f9)，研究日期 2026-11-11。结论来自静态源码比较，未运行客户端验证；「模块未见」不等于官方客户端缺失，落地前应先核验官方原生设置。

PiliPlus 自行请求资源、选择 DASH 表示并控制 media_kit 播放器；BBZQ 修改官方客户端的局部策略。值得借鉴的是需求、交互和不变量，不是引入 Flutter、mpv、独立缓冲层或第二套播放器。

## 候选与优先级

以下为候选评估，不是已实现清单。硬解当前实现另见[硬解策略](hardware-decoding.md)。

| 优先级 | 候选 | 主要切入点与限制 |
|---|---|---|
| P1 | 推荐时长、播放量、赞播比过滤 | 先补时长，其他指标默认关闭；缺失数据放行，关注豁免，过滤空页不无限补页 |
| P1 | 真实网络分档画质 | 与半/全屏偏好组合，不受伪装 Wi-Fi 干扰；手动选档优先，不覆盖账号授权 |
| P1 | 同规格硬解编码偏好 | 不跨编码比较码率大小，不删唯一退路；格式未知保留原生 |
| P1 | 评论语义过滤 | 商品元数据、纯 @、@ 数量等结构化规则；复用现有评论管线 |
| P1 | 动态正文和转发源过滤 | 正文、商品卡、原文分别判断；保留分页和作者上下文 |
| P2 | 独立音质与网络偏好 | 不与音频 CDN 混淆，保留不可用或无声时的退路；原生已能记忆则不重复实现 |
| P2 | 非 AI、语言与静音字幕策略 | 遍历候选而非仅看首项；用户手动关闭优先，异步结果按会话校验 |
| P2 | 稍后再看搜索、筛选和排序 | 优先暴露宿主现有能力；删除、清理仍需确认，不自动批量操作账号 |
| P2 | 双击跳转和时长 | 不接管全局触摸；保留锁屏、无障碍、竖屏与暂停状态 |
| P2 | 无障碍控件隐藏超时 | 先核验系统推荐超时及宿主读屏支持，不盲目全局延长 |
| P2 | 自己成功发送评论的本地留档 | 账号隔离、明确 opt-in、可清除导出；不是全站历史恢复 |
| 探索 | 发评后可见性核验 | 有界额外请求，只报告查询结果，不把不可见直接解释为封禁；不传全量 Cookie 给外部工具 |
| P3 | 弹幕合并与细粒度策略 | 优先原生设置；若补去重需时间窗及原始 ID，不能逐帧反射过滤 |
| P3 | 到点后等本集结束的定时 | 先查原生；阻止连播而非杀进程 |
| P3 | 指定默认收藏夹快速收藏 | 明确目标夹和写操作，不照搬「已收藏即取消全部夹」 |
| 暂缓 | 播放器预初始化与缓冲调参 | mpv 参数不能直接套进官方 IJK；没有首帧、流量、内存和功耗证据不实施 |
| 暂缓 | 响度均衡与防削波 | 不引入完整 FFmpeg/mpv，不在 AudioTrack 热路径改 PCM，不绕过付费音效 |

签名安全的直连备源是现有能力的巩固，见[播放策略](playback.md)，不另建本地 HTTP 代理。长按倍速、后台播放、基础弹幕和空降助手存在大量重叠，不重复包装为新功能。

## 可复核的上游入口

以下路径均相对于固定研究提交，可在上方源码树中复核：

- `lib/utils/recommend_filter.dart`：推荐指标和关注豁免。
- `lib/utils/video_utils.dart`、`lib/pages/video/controller.dart`：网络预设、视频编码与音轨选择。
- `lib/grpc/reply.dart`、`lib/pages/common/reply/reply_controller.dart`：评论过滤和交互。
- `lib/models/dynamics/result.dart`、`lib/http/dynamics.dart`：正文、转发及分页。
- `lib/plugin/pl_player/controller.dart`、`view/view.dart`：无障碍超时、手势、初始化和缓冲。
- `lib/pages/later/controller.dart`、`lib/http/user.dart`：稍后再看筛选与清理。
- `lib/utils/reply_utils.dart`：发评后检查及外部工具路径。
- `lib/plugin/pl_player/models/hwdec_type.dart`：硬解配置；`hwdec-current` 为运行观测线索，设置存在不等于硬解成功。

## 实施与许可原则

- 按功能 opt-in，默认跟随原生；符号失效、响应未知、会话不匹配时放行。
- 仅选择服务端已为当前账号提供的可播资源，不补造购买或授权状态。
- 复用既有响应管线，缓存反射访问器，不逐帧扫类或增加每张卡片的网络请求。

- 没有构建和真机结果，不宣称上述候选已适配或已带来性能收益。
