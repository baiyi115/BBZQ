# 硬件解码优先策略

## 功能语义

「尽可能优先硬件解码」默认关闭。开启后，在普通视频链路扩展硬件组件识别与选择，并在同画质、尺寸、帧率的候选中稳定前置硬件匹配项。不自动提高请求画质，不删除软件、未知或重复备选，不禁用官方软件激活和 native 错误恢复。

HDR、DRM、透明视频、取帧、raw data、音频预加载等特殊路径保持原生；必要字段或入口签名变化时不接管。更改针对后续请求和新建播放项，不能即时重建当前解码器，也不能保证任何异常下视频必定播放成功。

## 能力检测与组件选择

[`CodecCapability`](../app/src/main/java/io/github/bbzq/feats/hook/mbgeb/CodecCapability.kt) 枚举 `ALL_CODECS`，保存组件名称、MIME 和能力对象：

- 排除编码器、软件组件、alias，以及要求 secure/tunneled 的实现。
- API 29+ 使用系统 hardware/software 分类；API 28 仅识别有限厂商前缀，未知名称不算已确认硬件。
- 检测 AVC、HEVC、AV1、VVC，收集 Dolby Vision 声明但不接管其播放路径。
- 在同一个组件上检查已知尺寸、帧率、码率；缺失 profile/level 时只作有限匹配，不把编码 ID 或 QN 当作位深证明。
- 完整结果进程内复用；查询异常以受控间隔重试，不逐响应枚举。

优先保留官方已选的硬件名称。没有已识别的官方硬件名时，仅补选唯一硬件组件；多个组件但缺少当前流格式绑定时，不按系统枚举顺序猜测最优。响应排序也只使用同一可确定组件进行能力匹配。

**不保证使用性能最好的组件。** 声明支持不等于创建成功；最大吞吐、最低功耗、起播速度和稳定性并非同一指标，需真机对照测量。

## 官方播放器适配

静态分析基线为官方 Android 9.3.0（9030300），样本 SHA-256：

`c7e0059504157109cf26da63504ab115e32e28b302acdb52bd457cdcc5c0c70b`

以下为该样本的静态机制，不代表所有版本或设备：

- 普通视频默认启用硬解，但还受组件评分、白名单及 AV1/VVC 主动软件激活策略影响。
- `IjkMediaPlayerItem` 初次提交 native 流列表早于 `setItemOptions`；因此只在设置选项时开启 HEVC 可能已经过晚。
- `mediaAssetToJson` 通过 `IjkCodecHelper.isAv1SupportInternal` / `isH266SupportHard` 决定部分流是否准入。仅补 item 的组件名称不足以打通准入。
- 软件 activation 同时影响哪些软件流能进入 native，不能通过跳过整个方法来保证保留退路。

[`HardwareDecoderHook`](../app/src/main/java/io/github/bbzq/feats/hook/mbgeb/HardwareDecoderHook.kt) 在主进程转换前准备配置，仅在该普通 item 的转换调用线程范围内补充 AV1/VVC 硬件准入；正常和异常退出均恢复线程上下文。原转换调用恰好执行一次，不因异常重复提交。

不写 `decoder_type` 整数，不修改 native 偏移、解码竞速或错误回退参数，不全局劫持 `MediaCodec`，不循环重开播放器。

## 候选统计不是运行状态

简介中的「视频数据」显示最近响应候选，不是当前播放实例的实际解码器。没有候选时清除旧统计；未知编码不标成 AAC。预加载和异步乱序尚未与播放实例严格绑定。

官方 `getVideoDecoder()` 属性 20003 和 `getMediaInfo()` 中的 `video_codec_info` 可提供运行观测线索，但本功能尚未接入实例采样。MediaCodec 也可能是软件实现，仍需结合实际实现名和系统分类。

## 测试与验收

新增用例覆盖稳定排序、不同档位槽位不变、软件及重复备选保留、帧率解析、单候选 QN 修正、空 DASH/URL、嵌套响应、HDR 退路、未知编码、列表写入读回及多组件不盲选。

本次仅完成静态检查，未编译、执行测试、验证 CI 或真机。静态核对不能证明实际硬解、失败恢复成功或功耗下降。发布前至少验证：

1. 固定设备、视频、画质、帧率、动态范围、亮度和网络，对照原生与单项开关。
2. 记录实际 decoder 类型/名称、失败原因、切流及恢复后的状态。
3. 覆盖未知格式、初始化失败、seek、连播、快速切换、预加载和退出重进。
4. 比较首帧、重缓冲、掉帧、CPU、温度和稳态能耗；基线已使用同一硬解器时，不宣称重复开启带来节能。
